### 🚀 Featured Projects

#### 🔗 **[LinkHub — Enterprise Link Management Platform](https://github.com/Mohansivakumar017)**
> *A high-performance, multi-tenant link management platform built with Clean Architecture & Repository Pattern.*
- **Backend & Async**: FastAPI, PostgreSQL, SQLAlchemy, Redis caching, Celery workers for asynchronous analytics and scheduled jobs.
- **Security**: JWT authentication with refresh-token rotation, bcrypt hashing, and fine-grained Role-Based Access Control (RBAC).
- **Core Engine**: Custom aliases, self-expiring & one-time links, click quotas, bulk operations, rate limiting, and comprehensive click analytics (device, browser, geolocation).
- **DevOps**: Fully containerized using Docker, structured logging, health checks, and pytest test suite.

#### ⛅ **[Weather Monitoring & Alert System](https://github.com/Mohansivakumar017)**
> *Real-time environmental monitoring platform with automated alert triggers.*
- **Architecture**: Flask REST API integrated with third-party weather APIs and automated alerting via **AWS SNS**.
- **Cloud Infrastructure**: Deployed on **AWS EC2, S3, and CloudWatch** for live monitoring, logging, and metrics.
